07 / Design notes

What the model assumes

Bisonoric logic: each physical button has two independent pitches, selected by bellows direction. The virtual manual can expand from 21 to 60 buttons; rows are generated from scale-degree lattices, while the chromatic layout advances directly through EDO steps. Changing temperament quantizes pitch positions into the chosen EDO.

Harmony pads: chord templates are reference interval sets quantized into the active EDO. Capture A/B stores exact EDO pitch coordinates so alternatives can be auditioned and compared without losing the current voicing.

Voice diagnostics: every Web Audio oscillator pair is registered until both oscillators end. Held keys are tracked by pointer or keyboard owner; pointer cancellation, lost focus, page hiding and an optional watchdog release them. Panic also cancels future sequencer voices, not only manually held keys.

Consonance model: the field compares each interval against a weighted set of just-intonation reference ratios. This is a pedagogical heuristic, not a universal psychoacoustic law; register, timbre, cultural context and harmonic function matter.

Microtonal MIDI: export uses MIDI 1.0 Type 1, with one track and channel for each monophonic sequencer lane. Each note is encoded as the nearest 12-TET key number plus a 14-bit pitch bend for its remaining cents. RPN 0,0 communicates the bend range to the receiving instrument. Pitch bend is channel-wide in MIDI 1.0, so the separate lane channels prevent one voice from detuning another. This is channel-per-lane MIDI, not MPE or per-note pitch bend within a channel; the receiving instrument or DAW must preserve the channels.

Temporal model: sequencer columns are evaluated as simultaneous sonorities. The transition score additionally considers same-lane motion between adjacent steps. It does not assume that every dissonance must resolve immediately.

Research caution: a 24-EDO grid has 50-cent steps, but an actual quarter-tone accordion may use selected altered reeds rather than a fully quarter-tone keyboard. Here every pitch is available to the virtual instrument.

The scale presets labelled “inspired” are deliberately approximate educational collections. They are not authoritative transcriptions of a maqām or a regional tuning tradition.

Reading the colours

Interpretive guide

Vertical / harmonic: each sequencer column forms a chord from all active lanes. The fill colour expresses its average pairwise interval consonance. The manual's button halos instead compare a note with the tonic and with the current harmony pad.

Horizontal / temporal: moving between columns changes the same voice's pitch. The transition label reports average motion in cents and a combined score; it can reveal smooth voice-leading even when the chord itself is tense.

Resolution candidates: for the current harmony pad, the tool tests nearby one- and two-division movements for each selected pitch and ranks the replacements that improve the aggregate consonance score. A high score is not a command to resolve.
